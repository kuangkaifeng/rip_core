## 3. 几何模型（已用 100×100 / 720×720 / 金样本验证）

### 3.1 内容尺寸（单位：page unit，A3 mode2/3 时 720/in）

```
content_w_units = round(img_w_px * modeHDpi / imgDpi)      // mode2/3: img_w*6, imgDpi≈120
content_h_units = round(img_h_px * modeVDpi / imgDpi)      // mode2/3: img_h*6
```

- **图像物理 DPI 取 PNG 内嵌值**（`pHYs`；工具生成的图都是 119.9896≈120）；`view.xdpi/ydpi` 无效。
- `M`（页边距常数，单位 page unit）与模式有关（实测）：mode0/1 = **245**；mode2/3 = **555**；mode5/7/9 = **1227**。
- ESC(S = `(content_w_units, content_h_units - M)`；ESC(c = `(-M, content_h_units + M)`。
  - 注意：小图（如 64px, mode2）时 `content_h_units - M = 384-555 < 0`，蒙泰直接写成 u32 回绕（`0xFFFF...`），我们应原样复刻（否则无法逐字节一致）。

### 3.2 光栅行与页面行的关系

- 每块 `m = 90` 行，`n = align4(ceil(content_w_dots / 4))`（2bit/像素，行尾补 0），`depth=2`，`comp=1`(RLE)。
- 块序号 k，块起点位置 `pos_k` = 累计垂直推进（单位 page unit）：首块之后每个块前有 `ESC ( v <advance>`。
- **光栅行 r（0..89）对应的页面行**：`page_row = pos_k + VSTEP * r`，其中 `VSTEP = r / v = 1440/16 = 90dpi` 换算成 page unit：
  - mode2/3（page unit=720/in）：`VSTEP = 8`
  - mode0/1（page unit=360/in）：`VSTEP = 4`
- 内容映射（已验证 Jaccard≈0.89~0.99）：
  ```
  page_row = P0 + rowStep * image_row     // 金样本 mode2: rowStep=6 (=720/120), P0≈644
  page_col = colStep * image_col          // colStep=6, 偏移 0
  ```
  `P0` 的精确公式待定（与 ESC(c 的 -M、首块 advance 相关；金样本 644，100×100 纯色样本内容行 p∈[640..1243]）。

### 3.3 块推进与块数（mode2，100×100@120dpi 输入）

- 每色每行 2bit 打包，`n=152`（600 dots/4=150 → 补齐 4 字节到 152）。
- 每块 4 色，记录顺序实测 `[0x04(K), 0x00(C), 0x12(M), 0x11(Y)]`；6 色模式为 6 条记录（顺序见语料）。
- `ESC ( $` 参数：本模式恒 `0`（与厂商 `test.prn` 的 `floor(块/16)%4` 不同，说明该参数与驱动/模式相关）。
- 块推进与块数实测（A3，100×100 输入）：

| modeId | 通道数 | adv | 块数 | ESC(U) | ESC(S) | ESC(c) |
|---|---|---|---|---|---|---|
| 0 | 4 | 71 | 9 | 08 08 04 | (300, 55) | (-245, 545) |
| 1 | 6 | 35 | 18 | 08 08 04 | (300, 23) | (-277, 577) |
| 2 | 4 | 79 | 16 | 04 04 04 | (600, 45) | (-555, 1155) |
| 3 | 6 | 39 | 33 | 04 04 04 | (600, 13) | (-587, 1187) |

- 块数的经验拟合（mode2）：`blocks ≈ ceil(8*N/adv) + 8`，其中 `N = ceil(content_h_units / VSTEP)` 为内容光栅行数。已用 100px(16)、720px(63)、64px(13) 三组验证；**金样本 49 块不符合**（见 3.4）。
- 大图样例：720×720 输入 → 63 块；S=(4320,3765)、c=(-555,4875)。

### 3.4 空白跳过（金样本异常）

金样本（718×654，含大片透明/白色区域）实测：49 块，advance 序列 = `[150, 79×47, 349, 79...]`（共 49 个推进值，位置 150→4212）。与均匀 adv=79 的期望块数（58）不一致，且出现首块前 150、中途 349 两个异常值 ⇒ **蒙泰对整块空白区域做了“跳过/合并”优化**（空白带用更大 advance 跳过）。待 escp2-analyst 定稿规则。

### 3.5 重叠带与点阵拆分（重要！）

- 由于块 k 与 k+8 的位置相差 `8*adv`，而光栅行步进 VSTEP=8，同一 `page_row` 会被 **两块同时覆盖**（约 88 行/632 行的比例）。
- 实测两块在该行上的点阵是**互斥拆分**（同一像素不会两边都喷；`both=0`），即蒙泰把一行点阵按某种规则分给两趟打印（羽化/交织，避免接缝）。
- 拆分规则待定（候选：按 x 位置的周期性掩码，与块号/行号相位相关）。这是“逐字节复刻”的最后关键点之一；只求“能正常打印”时可先用自定义掩码。

## 4. 2bit 打包与 RLE

- 2bit/像素，**高位在前**：像素 x → 字节 x/4，bit 位置 `6 - 2*(x%4)`；值 0..3 = 不喷/小点/中点/大点。
- RLE（每条 ESC i 记录独立，按行边界可跨行）：
  ```
  c = 0..127  → 复制后续 (c+1) 字节
  c = 128..255→ 下一字节重复 (257-c) 次
  ```
- 每条记录后跟 `0D`。

## 5. 颜色码 → 墨水（实测）

`0x00=C, 0x04=K, 0x11=Y, 0x12=M, 0x01=W1, 0x02=W2`（用纯 RGB/CMYK 色块图对照：纯红只有 0x12/0x11，纯蓝只有 0x00/0x12，纯绿只有 0x00/0x11，纯黑四色都有）。
RGB→CMY 近似 `C=255-R, M=255-G, Y=255-B`；K 由后处理/ICC 决定（纯黑有 K，纯色无 K，说明是 UCR/GCR 或 ICC 结果；见 `docs/color_pipeline.md`）。
