**律：整幅平均 2-bit 点值 = 3·v/255（v=16..240 全部实测误差 <1e-4）。**
即 RIP 把 8-bit 墨量均匀分配到“每像素 0/1/2/3”四级点：
`v<85` 时只用小点(1)、覆盖率 = 3v/255；`85≤v<170` 覆盖率 100%、小点↔中点按比例混合；
`v≥170` 覆盖率 100%、中点↔大点按比例混合。**这就是 2-bit 多值加网的核心量化律，可直接实现。**

## 6. 初步结论

1. **CMYK TIFF 可作输入**（mode2/mode0/H13 全部 result=0）；CMYK TIFF 的通道被直接当作设备墨量处理（mode2 无 ICC 校色）。
2. **单通道墨值 → 颜色码映射（A3 mode2/m0 实测）**：C→`0x00`，K→`0x04`，Y→`0x11`，M→`0x12`（另：A3 6 平面模式还有 0x01/0x02 两个颜色码，见 T2/T3）。
3. **2-bit 多值加网量化律（核心！）**：整幅平均点值 = `3·v/255`（v=16..240 实测误差<1e-4）。
   即每像素 2-bit 值 k∈{0,1,2,3} 代表 0/1/3、2/3、3/3 的墨量：
   - `v < 85`：只用小点(1)，非零覆盖率 = 3v/255（实测 v=16→0.188、64→0.753、80→0.941）；
   - `85 ≤ v < 170`：覆盖率 100%，小点↔中点混合（v=96: 87%:13%；128: 50%:50%；160: 12%:88%）；
   - `v ≥ 170`：覆盖率 100%，中点↔大点混合（176: 93%:7%；192: 74%:26%；240: 18%:82%；255: 全大点）。
   点型空间排布呈伪随机（类误差扩散/蓝噪声，见 §3.4 样例），不是规则 AM 网点。
4. **PRN 体积与点型均匀度相关**：单一大点满版仅 ~19.9 KB（RLE 易压），混合点型 ~51 KB。
5. **720×360 与 720×720（mode0/m2）加网点型规律一致**，仅纵向输出行数不同（W×H 分别为 img×6×img×3 与 img×6×img×6），说明挂网模板/点型规律由驱动 prs 决定、与纵向分辨率档位无关。
6. H13 输出 HSSF 定长帧（456,048 B@m0），无法用 ESC/P2 解析器看内部点阵，交 T4。
7. **mtcount 不可用**（result=1 用户取消），点型统计只能靠解码 PRN 自行统计。

### 9.2 阈值场 T1/T2/T3（供加网模型拟合）

对 C 通道 256 个 PRN 的同一光栅位置，记录 2-bit level 首次达到 1/2/3 的 t，得到三个阈值数组（各 449280 个 uint16，光栅顺序）。

* 文件：`work/protocol/evidence/probe_scan_thresholds.bin`（T1[449280] T2[449280] T3[449280]，各 uint16 LE；raster order：block-major→record-major→row-major，每字节 4 像素 LSB-first，96×4 像素/行、90 行/record、13 records；A3 mode2 C 通道）；
* **重要**：449,280 个光栅位置中只有 **147,456 = 384×384** 是页面内像素，其余 301,824 个是微步进（microweave）块的空白填充行，始终为 0（T1=0）。拟合 U 时请只取 `T1>0` 的位置；
* 对应模型：`level(t) = floor(3t/255) + [frac(3t/255) > U(x,y)]` ⇒ `T1 = min{t : 3t/255 > U}`，即 **U ∈ ((T1−1)·3/255, T1·3/255]**；
* 实测：`T1>0` 共 147456 个位置，T1 ∈ [1, 85] 且 1..85 每级计数近似相等（≈1734/级）⇒ **阈值场 U 在 (0,1] 近似均匀分布（stochastic/FM 特征）**；
* T2−T1 分布 `{'84': 28, '85': 147428}`、T3−T2 分布 `{'84': 3, '85': 147421, '86': 28}`：集中在 **85/86**，即阈值场以 255/3=85 的墨量周期复现，与模型形式一致；
* 摘要见 `work/protocol/evidence/probe_scan_thresholds_summary.json`。

## 12. Oracle 侧可复现的加网缺陷（确定性）——最终报告必须注明

结论（T1 + T3 独立复核一致）：**不是非确定性，而是蒙泰侧可复现的算法缺陷**。
1024 个 tone 探针中 972 个 100%；52 个异常探针（13 tone × 4 ink）各 16 个像素，
共 **832 个异常 cell**，全部是 tile 中 T3==0（D<3，max level=2）的像素，
表现为 **oracle 非单调漏点**（level 随 tone 升高反而掉回 0，tone±1/±2 正常）。

| 项 | 内容 |

| 缺陷 tone（四通道相同） | `[93,95,101,106,151,161,166,186,202,230,242,244,253]` |
| 异常 cell | 13 tone × 4 ink × 16 位置 = **832** |
| oracle 行为 | 本 tone level=0（模型期望 1~2），邻域 tone 有 ink（非单调） |
| 确定性验证（T1） | 52 个作业各重跑 2 次：TI 归一化后 **52/52 逐字节一致**；内容平面 **0 像素差异**；**832/832 cell** 原始==r1==r2 且 == 审计 oracle_dot=0；**832/832 为非单调漏点** |
